# YOLOPX 实验运行详细指南

## 文件位置说明

### 1. 主要实验脚本

有两个主要的实验脚本：

#### a) 模拟TCI实验（快速验证）
**位置**: `/workspace/YOLOPX/yolop_series/unified_experiment_v2.py`
- 使用预设的TCI值进行快速对比
- 不需要实际加载模型和数据
- 适合快速验证实验框架

#### b) 真实梯度冲突实验（推荐）
**位置**: `/workspace/YOLOPX/experiments/real_tci_experiment.py`
- 实际加载模型并计算梯度
- 通过梯度的余弦相似度计算真实的任务冲突
- 虽然模型前向传播有问题，但通过模拟损失仍能计算梯度冲突

### 2. 运行方法

模拟实验：
```bash
cd /workspace/YOLOPX
python3 yolop_series/unified_experiment_v2.py
```

真实梯度实验：
```bash
cd /workspace/YOLOPX
python3 experiments/real_tci_experiment.py
```

### 5. 关于日志文件
`logs/` 目录下的文件是之前失败的实验尝试记录，显示的是命令行参数错误。当前的 `unified_experiment_v2.py` 是一个模拟实验，不产生训练日志。

### 6. 实验类型说明

#### 模拟实验 (unified_experiment_v2.py)
- 使用预设的TCI值来模拟不同模型的任务冲突特性
- 不需要实际的数据集和模型训练
- 主要用于验证实验框架和展示不同模型间的相对关系

#### 真实梯度实验 (real_tci_experiment.py)
- 实际加载YOLOP系列模型
- 通过计算不同任务梯度间的余弦相似度来评估冲突
- 虽然前向传播可能失败，但使用模拟损失仍能计算真实的梯度冲突
- 结果更能反映模型架构对任务冲突的影响

### 7. 关于实验中的日志文件
- `logs/` 目录下的文件是之前使用 `run_conflict_comparison_experiment.py` 的失败尝试
- 当前推荐的两个实验脚本都不会生成训练日志，而是直接输出TCI计算结果
