# YOLOPX - 多任务学习冲突研究平台

## 1. 项目概述

本项目旨在深入研究多任务学习（Multi-Task Learning, MTL）中的任务间冲突问题，并探索有效的解决方案。项目以 **YOLOP** (You Only Look Once for Panoptic Driving Perception) 模型为基线，通过改进和重构，构建了一个名为 **YOLOPX** 的实验平台。

YOLOPX 的核心目标是：
- **横向比较**：在统一的框架下，公平地比较多种主流的任务冲突解决策略（如 PCGrad, GradNorm, CAGrad, TAG 等）。
- **纵向比较**：方便地在原始的 YOLOP 和集成了冲突解决方案的 YOLOPX 之间进行性能切换和对比。
- **接口化设计**：为未来集成新的、自定义的任务冲突解决方法提供一个清晰、可扩展的接口。

## 2. 研究方法

本研究采用基于梯度的多任务优化方法，核心思想是在反向传播过程中，通过特定策略调整或修改来自不同任务头的梯度，以缓解它们之间的冲突，从而提升模型的整体性能。

- **基线模型**: YOLOP，一个用于全景驾驶感知的多任务模型，包含**交通目标检测**、**可行驶区域分割**和**车道线分割**三个任务。
- **核心模块**:
    - **版本 V1**: 初步探索 YOLOP 中的任务冲突现象的代码实现。
    - **版本 V2**: 经过重构的、模块化的代码库。它将模型、训练引擎、冲突求解器等解耦，使其可以灵活地组合不同的实验配置。
- **冲突解决方案**:
    - 在 `v2/mtl/` 目录下实现了多种经典的梯度平衡算法，方便调用和比较。

## 3. 代码结构

重构后的 `YOLOPX` 目录结构清晰，职责分明：

- **`/v1`**: 原始研究代码，用于复现早期的实验。
- **`/v2`**: 当前核心实验平台。
    - `v2/cfgs`: 存放模型和实验的配置文件。
    - `v2/data`: 数据集处理与加载模块。
    - `v2/engine`: 训练和评估的核心引擎。
    - `v2/models`: YOLOPX 模型定义。
    - `v2/mtl`: 实现各种多任务冲突解决方案的模块。
    - `v2/tools`: 用于启动训练、评估和分析的脚本。
- **`/runs`**: 存放所有实验的日志、权重和结果。
- **`/bdd100k`**: (位于 `/workspace/bdd100k`) BDD100K 数据集。

## 4. 实验与环境

- **数据集**: BDD100K
- **核心依赖**:
    - Python 3.8+
    - PyTorch 1.10+
    - CUDA 11.3+
    - Weights & Biases (用于日志记录和可视化)
- **启动实验**:
  ```bash
  # 进入 v2 工作目录
  cd YOLOPX/v2
  
  # 运行训练脚本，method 参数用于指定冲突解决方法
  python3 tools/train.py --method pcgrad --cfg cfgs/your_config.yaml
  ```
